# Glow-Spa

> Luxury wellness sanctuary web application for **Glow Spa** (formerly Glow Spa) located in Kalaburagi (Gulbarga), Karnataka.

## 🌿 Highlights & Architectural Features

- **3D Scroll-Driven Virtual Camera Walkthrough:** Non-blocking hardware-accelerated video scroll-scrubbing engine synchronised with Lenis inertial scrolling across 300vh.
- **Brand Identity & Favicon:** Custom sage-green meditation lotus insignia and typography.
- **Interactive Modality Catalog:** 12 curated therapies including Mediterranean Turkish Hammams, Kerala Ayurvedic Abhyanga, Swedish Relaxation, Deep Muscle Release, and VIP Couples Suites with transparent pricing and real-time category filtering.
- **Spatial Gallery Lightbox:** High-resolution architectural tours of the walnut fluted arrival desk, crystal chandelier lounge, chromotherapy suites, and en-suite frosted glass showers.
- **Area-by-Area Wellness Library (10 4K Starter Guides):** Tailored guides for Daryapur, Ram Mandir Circle, Kotnoor D, GDA Layout, Old Jewargi Road, Station Road, Sedam Road, Biddapur Colony, Mecca Colony, and Godutai Nagar.
- **50-Locality & Arterial Road Directory:** Instant live search and booking checklists for 50 Kalaburagi neighborhoods.
- **Web Audio API Ambient Soundscape:** Interactive 432Hz ambient meditation audio generator with dynamic equalizer animation.
- **Day & Chromotherapy Night Spa Ambience:** Smooth theme switcher between Daytime Alabaster Marble and Violet Chromotherapy Night Mode.
- **Interactive Cartography:** Custom-styled Leaflet map pinpointing the sanctuary entrance along Ram Mandir Service Road above Onyx Italian Marble Store.
- **WhatsApp Reservation Concierge:** Real-time pre-filled message generator for seamless one-tap bookings.
- **Fully Responsive Architecture:** Optimized for desktop, tablet, and mobile devices (tested down to 320px).

## 🛠️ Technology Stack

- **Core:** Modern HTML5 & Vanilla JavaScript (ES Modules)
- **Styling:** Curated Vanilla CSS Design Tokens (Glassmorphism, CSS Grid, Flexbox)
- **Animation & Scroll:** [GSAP 3](https://greensock.com/gsap/) (ScrollTrigger) & [Lenis](https://github.com/darkroomengineering/lenis) (Smooth Inertial Scrolling)
- **Audio:** Native Web Audio API Synthesized Soundscape
- **Maps:** [Leaflet.js](https://leafletjs.com/) with CartoDB Positron / Dark Matter tiles
- **Bundler:** [Vite](https://vitejs.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Development

```bash
# Clone the repository
git clone https://github.com/nitin-guttedar/Glow-Spa.git
cd Glow-Spa

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Compile and optimize production bundle
npm run build

# Preview production build locally
npm run preview
```
